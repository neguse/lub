# 12_avocado.gltf / 12_avocado.bin

Geometry from the Khronos **Avocado** glTF sample asset.

- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Avocado
- © 2017, Public.
- License: **CC0 1.0 Universal** (public domain) —

Only the geometry (`.gltf` + `.bin`: POSITION / NORMAL / TEXCOORD_0 / TANGENT)
is vendored here; the original baseColor / normal / roughnessMetallic PNG
textures are **not** included (the showcase applies its own generated maps).
The `.gltf` `buffers[0].uri` was renamed to `12_avocado.bin` to match.
