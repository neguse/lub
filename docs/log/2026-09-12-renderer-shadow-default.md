# コインの bias と共通の既定値

[自己影の修正](2026-09-12-coin-shadow-fix.md) の後、`26_renderer3d` の比較画像を見直した。
共通の bias を 0.0001 にすると、雪だるまの表面に以前より細かな影が出た。
このモデルでは 0.004 を維持すると粒状の模様が抑えられる。

受け面の深度補正と PCF の補間は共通の修正として保ち、bias の既定値は従来の 0.004 を維持する。
`18_coin_pusher` には検証した 0.0001 を明示する。
コインの比較サンプルと回帰テストも、このコイン側の値を使う。
物体の寸法と影の範囲に応じた設定を、共通の既定値に押し込まない。

コインの実際の描画に渡す値は 3 分間の確認時と同じ 0.0001 で、
Vulkan / SDL GPU の既存のコイン基準画像との一致も確認する。
共通の既定値を変えずに、別モデルの副作用を防ぐための調整。
