# Lider の窓の仕組み: 合意の記録

> 記録: 2026-11-15 に始めた、Lider の窓の仕組み (`Space`、`Screen`、`Window`、`ILayout`) について合意したことの一覧。話し合いが進むたびに足す。

## 決まり

- 載せるのは、利用者が明示的に OK と言った項目だけにする。
- 各項目に、もとになった利用者の言葉を添える。
- ここに無いものは実装しない。

## 決めていないこと

- `Window` そのものに奥行きの大きさを持たせるか (ゲームの場面を、スクリーンの上の決まった大きさの箱の中に立体で出す形)。作って見ないとわからない。
- ゲームの場面をワールドにそのまま描いた物が複数重なるときの出し分け方 (透過度、目ごと)。やってみないとわからない。
- `Window` を持って動かしたときにできること。順番を変えるほかに、レイアウトを変える、別の `Screen` に移す、などが増えそう。
- `Screen` の見せ方 (輪郭、余白、指したときの光り方)。
- 既定の配置 (どの `Screen` を置き、どの `Window` をどこに並べるか)。
