# Box3D Phys3d API + Coin Pusher Sample Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- []`) syntax for tracking.

**Goal:** Box3D v0.1.0 (`third_party/box3d`, submodule pin 済み) を phys2d と同じ
immediate-mode key-based モデルで Lua/Haxe に公開し (`phys3d_*` globals +
`lub.Phys3d` extern)、コインプッシャーの sample 18 を native (sokol / sdlgpu) と
web playground の両方で動かす。

**Architecture:** `src/physics_box3d.{h,c}` に phys2d (`src/physics_box2d.c`) と
同型の C 実装を置く。設計 semantics (key 宣言 + 差分 create/update/destroy、
constructor hash / version rule、prune / tombstone、sentinel refs、event snapshot、
single-thread step 固定) は `docs/superpowers/specs/2026-06-09-box2d-immediate-mode-design.md`
をそのまま流用し、本 plan では 3D 化に伴う差分だけを規定する。

**Tech Stack:** C17 / Box3D v0.1.0 (MIT) / Lua 5.5 / Haxe 5 / Slang /
sokol_gfx / SDL3 GPU / WebGPU。

## Box2D 設計からの差分 (spec delta)

| 項目 | phys2d | phys3d |
|---|---|---|
| Prefix | `phys2d_*`, `b2*` | `phys3d_*`, `b3*` |
| Pose | `{x, y, angle}` | `{x, y, z, qx, qy, qz, qw}`。quaternion が canonical。descriptor の `initial` は `euler = {x,y,z}` (radian) も受け付け C 側で quat 化 |
| Vec | `{x, y}` | `{x, y, z}` |
| Shapes | box/circle/capsule/segment/polygon/chain | sphere / box / capsule / cylinder / cone / hull / mesh / height_field / compound。box/cylinder/cone/hull は内部的に `b3HullData` (`b3MakeBoxHull` / `b3CreateCylinder` / `b3CreateCone` / `b3CreateHull`) |
| Heavy geometry | chain のみ version 必須 | hull(points) / mesh / height_field / compound は version 必須 (chain と同ルール)。`b3CreateCylinder` 等の malloc 返しは shape 作成後に `b3DestroyHull`(コピー有無は実装時に header で確認) |
| Joints | distance/filter/motor/mouse/prismatic/revolute/weld/wheel | distance/filter/motor/**parallel**/prismatic/revolute/**spherical**/weld/wheel。mouse joint は無い |
| Events | body/contact/sensor/hit | + **joint events** (`b3World_GetJointEvents`) |
| Body 追加項目 | — | `motion_locks` (linear x/y/z + angular x/y/z)、gyroscopic 系 tuning |
| Kinematic 追従 | `body:set_target` | `b3Body_SetTargetTransform(body, transform, dt, wake)` を `phys3d_set_target` に |
| Explosion | `phys2d_explode` | v0.1.0 に該当 API 無し → 対象外 |
| Debug draw | geometry snapshot | upstream は retained debug shape callback 形式に変更 → Phase 4 で snapshot 翻訳を検討 (初期 scope 外) |
| Recording/replay | — | `b3Recording` / `b3RecPlayer` は non-goal |
| Callbacks | filter / pre_solve / friction / restitution | 同一セット (`b3World_SetCustomFilterCallback` 等)。single-thread 前提も同じ |

Naming 規則・descriptor の snake_case・collect/visitor 二形式の query・
`phys3d_begin`/`phys3d_step` の lifecycle は phys2d と完全に揃える。

## サンプル仕様: 18_coin_pusher

- 盤面: static body でトレイ (床 box + 左右壁 box + 奥壁 box)、手前は開口。
  一段高い棚 (box) の上を kinematic の pusher (box) が z 方向に正弦往復
  (`phys3d_set_target` で毎フレーム目標 pose を与える)。
- コイン: dynamic body + cylinder shape (radius 0.35 / height 0.1 / sides 24 程度)。
  key は `coin:<n>` の ring。`Input.keyDown("space") || Input.mouseDown(0)` で
  投入位置 (マウス x に追従) に spawn。デモ用に一定フレーム間隔の自動投入も入れ、
  golden 実行を deterministic にする。
- 落下回収: pose の y が閾値未満 (手前縁から落ちた) のコインは宣言をやめて
  prune で消し、スコアを加算。手前に落ちれば得点、横漏れは没収などの区別は任意。
- 描画: `lub.Math` で view/proj を組み、box / cylinder の頂点 (位置+法線) を
  Haxe 側で procedural 生成して `use_buffer`。directional lit shader、depth on。
  カメラは斜め上から盤面を見る固定視点。contact begin でコインを一瞬発光
  (16_box2d の contactFlash 踏襲)。
- 目安: 常時 30〜60 コイン程度。パフォーマンス問題が出たら substeps を調整。
