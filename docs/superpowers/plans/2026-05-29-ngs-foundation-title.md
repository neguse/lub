# NGS Foundation + Title Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** lub Phase 1 (NGS port) の最初の出荷可能増分 — sprite 描画基盤・bitmap font・入力・scene framework を建て、NGS タイトル画面が描画され、cursor 操作と "start"→Play placeholder / "end"→quit が動き、golden で固定できる状態にする。

**Architecture:** 設計 spec は `docs/superpowers/specs/2026-05-29-ngs-port-design.md`。フルゲーム (title→boss→game over) を 1 spec にまとめてあるが、実装は 4 plan に分割する。本 plan は **Plan 1 / 4 (Foundation + Title)**。Plan 2 = Player + 1 enemy、Plan 3 = full enemy roster、Plan 4 = Boss + game over (別 plan で起こす)。本 plan のスコープは「タイトルが遊べて golden が撮れる」まで。Play は player sprite を出すだけの placeholder に留め、enemy/spawner/collision は Plan 2 以降。

**Tech Stack:** Haxe 4.3.7 → Lua 5.5 transpile (lub の `.hxml` pipeline)、slang shader (`LUB_TEXTURE2D`/`LUB_SAMPLE` macro)、lub `Gfx`/`Input`/`Io` extern、Python (asset 変換)、C (lub runtime: window size + quit)、golden = lavapipe + xvfb 下の PNG byte 一致。

## 重要: 実装前に把握すべき検証済み事実

この plan は以下を実機で検証済み。これらは spec 本文より優先する。

1. **entry class は empty-package の top-level でなければならない。** Haxe lua target は packaged class `ngs.Main` を global `__ngs_Main` に出力する。lub の postlude は hxml の `-main <Name>` 文字列をそのまま `return <Name>` にするため、`return ngs.Main` は nil 参照で失敗する。top-level `class NgsMain` は `local NgsMain` として出力され `return NgsMain` が解決する (既存サンプル全てがこの形)。→ **entry = `samples/ngs/NgsMain.hx` の `class NgsMain` (package 宣言なし)**。補助クラスは package (`render` / `input` / `scenes` / `game` / `assets`) 自由に使える (Haxe が `__render_DrawList` 等の global として内部解決する)。

2. **empty package のクラスは package 内クラスから参照できない (Haxe の制約)。** `package scenes` の `Title` から root の `NgsMain` や root の `Atlases` を参照すると "Cannot access a type from the top-level package" でコンパイル不能。import も不可 (root package は import 構文に書けない)。逆方向 (root の NgsMain が `import game.Game` する) は OK。→ **共有 runtime 状態 (gfx / atlas / font / input / scene / frameCount) は packaged な `game.Game` に置き、NgsMain は `Game.init()`/`Game.frame()` を呼ぶだけの薄い forwarder にする。生成される `Atlases` も `package assets` に入れる (`assets.Atlases`)。** scenes/entities は `game.Game`・`assets.Atlases`・`render.*` を参照し、NgsMain には一切触れない。

3. **sprite shader は uniform 不使用で書く。** 論理解像度は 640×480 固定なので VS で `pos.x/320-1`, `1-pos.y/240` と定数化。UV は DrawList が CPU 側で `srcRect / atlasSize` に正規化して頂点に焼く。ConstantBuffer/uniform binding を一切使わないことで draw 経路が 09_breakout と同じ単純さになる。

4. **draw / texture の opts (検証済み, `src/lua_api.c`):**
   - `Gfx.useTexture(key, w, h, fmt, px, version, {filter: Gfx.NEAREST, wrap: Gfx.CLAMP})` — 第 7 引数 opts で sampler 制御。pixel-art は NEAREST + CLAMP。
   - `Gfx.draw(count, {verts: vbuf, atlas: tex}, {shader: s, depth: false, cull: Gfx.NONE, blend: Gfx.ALPHA})`。bindings の texture key (`atlas`) は shader の `LUB_TEXTURE2D(atlas)` 名と一致させる。

5. **配列 indexing:** lub C 受け口に Haxe 配列リテラルを直接渡すと 0-indexed ズレが出る。`clear_color` や `useBuffer` の頂点データは `lua.Table.fromArray([...])` で 1-indexed 化する (transpile spec §配列の indexing)。名前付き field の anonymous struct は wrap 不要。

6. **capture / 実行:** golden は CLI で撮る。`scripts/run-headless.sh ./build/lub <entry.hxml> --capture <out.png> --capture-frame <N>`。capture は `app_frame_end` 後・`frame_index++` 前に走る (`SDL_AppIterate`)。frame 0 capture は「最初の onFrame 実行後」のフレーム。Haxe 側から `Gfx.capture` を呼ぶ必要はない。

7. **ビルド:** `./build/lub` はビルド済み。C を変更した task のみ `cmake --build build` が必要。Haxe/asset のみの task はリビルド不要 (lub が常駐 haxe server で hot build する)。

## Testing approach (この codebase の流儀)

lub には Haxe の xUnit harness が無い。検証は既存サンプルと同じく **build + run (headless) + golden PNG 比較 + 目視** で行う。本 plan もこれに従う (xUnit を新設しない — YAGNI / follow existing patterns)。

- **「失敗するテスト」** = まだ実装が無い状態で `run-headless.sh` 実行 → build error もしくは capture 未生成 / 画面が空、を確認する。
- **「通すテスト」** = 実装後に同コマンドで build success + capture 生成 + 期待した絵が出る、を確認する。
- ロジック単位 (Input edge 検知、DrawList 頂点計算、Font glyph rect) は Title golden が end-to-end で網羅する。純ロジックの独立検証が要る箇所は、その task 内で具体的な確認手順を示す。

```python
#!/usr/bin/env python3
# NGS asset converter: 8-bit indexed BMP -> RGBA8 PNG (palette idx 0 = transparent),
# NSP (ASCII text, "x,y,w,h," per line) -> samples/ngs/assets/Atlases.hx literal table.
import os, struct, zlib

# .../lub/samples/ngs/scripts から各 dir を解決。ngs は lub の兄弟。
HERE = os.path.dirname(os.path.abspath(__file__))
LUB_ROOT = os.path.abspath(os.path.join(HERE, "..", "..", ".."))   # .../lub
NGS_DIR = os.path.abspath(os.path.join(LUB_ROOT, "..", "ngs"))      # .../ngs
DATA_DIR = os.path.abspath(os.path.join(HERE, "..", "data"))
ASSETS_DIR = os.path.abspath(os.path.join(HERE, "..", "assets"))
ATLASES_HX = os.path.join(ASSETS_DIR, "Atlases.hx")

def read_indexed_bmp(path):
    with open(path, "rb") as f:
        b = f.read()
    if b[0:2] != b"BM":
        raise SystemExit(f"{path}: not a BMP")
    pixoff = struct.unpack_from("<I", b, 10)[0]
    hdr = struct.unpack_from("<I", b, 14)[0]
    w = struct.unpack_from("<i", b, 18)[0]
    h = struct.unpack_from("<i", b, 22)[0]
    bpp = struct.unpack_from("<H", b, 28)[0]
    if bpp != 8:
        raise SystemExit(f"{path}: expected 8bpp indexed, got {bpp}")
    pal_off = 14 + hdr
    ncol = struct.unpack_from("<I", b, 46)[0] or 256
    palette = []
    for i in range(ncol):
        bb, gg, rr, _ = b[pal_off + i*4 : pal_off + i*4 + 4]
        palette.append((rr, gg, bb))
    top_down = h < 0
    H = abs(h)
    row_size = (w + 3) & ~3   # rows padded to 4 bytes
    idx = [[0]*w for _ in range(H)]
    for ry in range(H):
        src_row = ry if top_down else (H - 1 - ry)
        base = pixoff + src_row * row_size
        for x in range(w):
            idx[ry][x] = b[base + x]
    return w, H, palette, idx

def write_png_rgba(path, w, h, rgba):  # rgba: bytes len w*h*4
    def chunk(tag, data):
        c = tag + data
        return struct.pack(">I", len(data)) + c + struct.pack(">I", zlib.crc32(c) & 0xffffffff)
    sig = b"\x89PNG\r\n\x1a\n"
    ihdr = struct.pack(">IIBBBBB", w, h, 8, 6, 0, 0, 0)  # 8-bit, color type 6 (RGBA)
    raw = bytearray()
    for y in range(h):
        raw.append(0)  # filter none
        raw.extend(rgba[(y*w)*4 : (y*w + w)*4])
    idat = zlib.compress(bytes(raw), 9)
    with open(path, "wb") as f:
        f.write(sig + chunk(b"IHDR", ihdr) + chunk(b"IDAT", idat) + chunk(b"IEND", b""))

def bmp_to_png(name):
    w, h, pal, idx = read_indexed_bmp(os.path.join(NGS_DIR, name + ".bmp"))
    out = bytearray(w*h*4)
    for y in range(h):
        for x in range(w):
            ci = idx[y][x]
            r, g, b = pal[ci]
            o = (y*w + x)*4
            if ci == 0:
                out[o:o+4] = bytes((0, 0, 0, 0))       # palette idx 0 -> transparent
            else:
                out[o:o+4] = bytes((r, g, b, 255))
    write_png_rgba(os.path.join(DATA_DIR, name + ".png"), w, h, bytes(out))
    print(f"  {name}.png  {w}x{h}")

def read_nsp(name):
    # NSP format: plain ASCII text, one rect per line, "x,y,w,h," (trailing comma, CRLF).
    with open(os.path.join(NGS_DIR, name + ".nsp"), "r") as f:
        text = f.read()
    rects = []
    for line in text.splitlines():
        line = line.strip().rstrip(",")
        if not line:
            continue
        parts = [int(v) for v in line.split(",")]
        rects.append((parts[0], parts[1], parts[2], parts[3]))
    return rects

def gen_atlases():
    sheets = [("cursor", read_nsp("cursor")),
              ("jiki",   read_nsp("jiki")),
              ("enemy",  read_nsp("enemy"))]
    lines = ["package assets;", "",
             "// GENERATED by samples/ngs/scripts/convert.py — do not edit by hand.",
             "// Source NSP rect order is preserved (gameplay code indexes by number).",
             "import render.Rect;", "", "class Atlases {"]
    for nm, rects in sheets:
        lines.append(f"  public static final {nm}: Array<Rect> = [")
        for (x, y, w, h) in rects:
            lines.append(f"    {{ x: {x}, y: {y}, w: {w}, h: {h} }},")
        lines.append("  ];")
    lines.append("}")
    with open(ATLASES_HX, "w") as f:
        f.write("\n".join(lines) + "\n")
    print(f"  Atlases.hx ({sum(len(r) for _, r in sheets)} rects)")

def main():
    os.makedirs(DATA_DIR, exist_ok=True)
    os.makedirs(ASSETS_DIR, exist_ok=True)
    print("BMP -> PNG:")
    for nm in ("cursor", "jiki", "enemy", "font"):
        bmp_to_png(nm)
    print("NSP -> Atlases.hx:")
    gen_atlases()

if __name__ == "__main__":
    main()
```

```haxe
import lub.Gfx;
```

```haxe
class Atlas {
  public var texture: Dynamic;
  public var w: Int;
  public var h: Int;
  public final key: String;
  final path: String;
  var version: Int = -1;

  public function new(key: String, path: String) {
    this.key = key;
    this.path = path;
    this.texture = null;
    this.w = 0;
    this.h = 0;
  }

  // 毎フレーム呼ぶ。PNG version が変わったら useTexture を再呼出 (hot reload 対応)。
  public function ensure(): Bool {

    if (r.pixels == null) return false;
    this.w = r.width;
    this.h = r.height;
    this.texture = Gfx.useTexture(key, r.width, r.height, r.format, r.pixels, r.version,
```

- [ ] **Step 3: DrawList**

`samples/ngs/render/DrawList.hx`。atlas key 毎に頂点バッファ (Array<Float>) を貯め、flush で 1 draw。STRIDE=8 (pos.xy,uv.xy,rgba)。

```haxe
package render;

import lub.Gfx;

class DrawList {
  public static inline var STRIDE: Int = 8;

  // atlas key -> { atlas, verts }
  final buckets = new Map<String, { atlas: Atlas, verts: Array<Float> }>();
  final order = new Array<String>();   // 挿入順を保ち draw 順を決定的に
  final shader: Dynamic;
  var meshVersion: Int = 0;

  public function new(shader: Dynamic) {
    this.shader = shader;
  }

  public function begin() {
    for (k in order) buckets.get(k).verts.resize(0);
  }

  inline function bucketFor(a: Atlas): Array<Float> {
    var b = buckets.get(a.key);
    if (b == null) {
      b = { atlas: a, verts: [] };
      buckets.set(a.key, b);
      order.push(a.key);
    }
    return b.verts;
  }

  inline function vtx(out: Array<Float>, x: Float, y: Float, u: Float, v: Float, c: Color) {
    out.push(x); out.push(y); out.push(u); out.push(v);
    out.push(c.r); out.push(c.g); out.push(c.b); out.push(c.a);
  }

  // src = atlas 内 pixel rect、dst = logical 画面 pixel での左上 (dx,dy)。
  public function sprite(a: Atlas, src: Rect, dx: Int, dy: Int, ?tint: Color) {
    var c = (tint == null) ? { r: 1.0, g: 1.0, b: 1.0, a: 1.0 } : tint;
    var u0 = src.x / a.w, v0 = src.y / a.h;
    var u1 = (src.x + src.w) / a.w, v1 = (src.y + src.h) / a.h;
    var x0 = dx, y0 = dy, x1 = dx + src.w, y1 = dy + src.h;
    var out = bucketFor(a);
    vtx(out, x0, y0, u0, v0, c); vtx(out, x1, y0, u1, v0, c); vtx(out, x1, y1, u1, v1, c);
    vtx(out, x0, y0, u0, v0, c); vtx(out, x1, y1, u1, v1, c); vtx(out, x0, y1, u0, v1, c);
  }

  // 単色矩形。white atlas (1x1) を使い uv 全域。
  public function quad(white: Atlas, x: Int, y: Int, w: Int, h: Int, c: Color) {
    var out = bucketFor(white);
    vtx(out, x, y, 0.5, 0.5, c); vtx(out, x + w, y, 0.5, 0.5, c); vtx(out, x + w, y + h, 0.5, 0.5, c);
    vtx(out, x, y, 0.5, 0.5, c); vtx(out, x + w, y + h, 0.5, 0.5, c); vtx(out, x, y + h, 0.5, 0.5, c);
  }

  public function flush() {
    meshVersion = meshVersion + 1;
    for (k in order) {
      var b = buckets.get(k);
      if (b.verts.length == 0) continue;
      var vbuf = Gfx.useBuffer("ngs_dl_" + k, Gfx.VERTEX, lua.Table.fromArray(b.verts), meshVersion);
      Gfx.draw(Std.int(b.verts.length / STRIDE),
        { verts: vbuf, atlas: b.atlas.texture },
        { shader: shader, depth: false, cull: Gfx.NONE, blend: Gfx.ALPHA });
    }
  }
}
```

- [ ] **Step 4: Gfx2d**

`samples/ngs/render/Gfx2d.hx`。sprite shader を確保し、1×1 white atlas を作り、beginFrame/endFrame で pass を囲む。DrawList を保持。

```haxe
package render;

import lub.Gfx;
import lub.Io;

class Gfx2d {
  public var drawList: DrawList;
  public var white: Atlas;     // quad 用 1x1 白
  var shader: Dynamic;
  var ready: Bool = false;

  public function new() {}

  // 毎フレーム冒頭で呼ぶ。shader/white を確保 (idempotent)。失敗時 false。
  public function ensure(): Bool {
    var vs = Io.loadText("samples/ngs/data/sprite.vs.slang");
    var fs = Io.loadText("samples/ngs/data/sprite.fs.slang");
    if (vs.text == null || fs.text == null) return false;
    shader = Gfx.useShader("ngs_sprite", vs.text, fs.text, vs.version ^ fs.version);
    if (white == null) {
      white = new Atlas("ngs_white", "");   // path 空: ensure() は呼ばず手動確保
      white.w = 1; white.h = 1;
    }
    // 1x1 白を毎フレーム同 version で確保 (cache hit)。
    white.texture = Gfx.useTexture("ngs_white", 1, 1, Gfx.RGBA8,
      lua.Table.fromArray([255, 255, 255, 255]), 1, { filter: Gfx.NEAREST, wrap: Gfx.CLAMP });
    if (drawList == null) drawList = new DrawList(shader);
    ready = true;
    return true;
  }

  public function beginFrame() {
    Gfx.beginPass({ target: Gfx.mainTex, clear_color: lua.Table.fromArray([0.0, 0.0, 0.0, 1.0]) });
    drawList.begin();
  }

  public function endFrame() {
    drawList.flush();
    Gfx.endPass();
  }
}
```

注: `DrawList` は構築時に shader を受けるが、hot reload で shader handle が変わっても `flush` 時に最新を使いたい。`DrawList.shader` を `var` にして `Gfx2d.ensure` で `drawList.shader = shader;` を毎フレーム代入する形に直す (下の Step 5 で対応)。

```haxe
package render;

class Font {
  public final atlas: Atlas;
  public static inline var GW: Int = 8;
  public static inline var GH: Int = 8;
  static inline var COLS: Int = 16;

  public function new(atlas: Atlas) {
    this.atlas = atlas;
  }

  // ASCII 0x20..0x7F を 16 列グリッドで引く。それ以外は空白扱い。
  public function drawString(dl: DrawList, x: Int, y: Int, s: String, ?tint: Color) {
    for (i in 0...s.length) {
      var ch = s.charCodeAt(i);
      if (ch < 0x20 || ch > 0x7f) continue;
      var gi = ch - 0x20;
      var col = gi % COLS;
      var row = Std.int(gi / COLS);
      var src: Rect = { x: col * GW, y: row * GH, w: GW, h: GH };
      dl.sprite(atlas, src, x + i * GW, y, tint);
    }
  }

  // 右寄せゼロ詰めなしの単純な整数描画 (width 桁、先頭ゼロ詰め)。
  public function drawInt(dl: DrawList, x: Int, y: Int, n: Int, width: Int, ?tint: Color) {
    var s = Std.string(n);
    while (s.length < width) s = "0" + s;
    drawString(dl, x, y, s, tint);
  }
}
```

```haxe
package game;

import lub.Lub;
import render.Gfx2d;
import render.Atlas;
import render.Font;
import input.InputSource;
import input.Input;
import input.MockInput;
import scenes.Scene;
import scenes.SceneTransition;

class Game {
  public static inline var W: Int = 640;
  public static inline var H: Int = 480;
  public static var gfx: Gfx2d = null;
  public static var fontAtlas: Atlas = null;
  public static var jikiAtlas: Atlas = null;
  public static var cursorAtlas: Atlas = null;
  public static var font: Font = null;
  static var input: InputSource = null;
  static var scene: Scene = null;
  public static var frameCount: Int = 0;

  public static function init() {
    var backend: String = lua.Os.getenv("LUB_BACKEND");
    if (backend == null) backend = "sokol";
    Lub.config({ backend: backend, width: W, height: H });
  }

  static function boot(): Bool {
    if (gfx == null) gfx = new Gfx2d();
    if (fontAtlas == null) fontAtlas = new Atlas("ngs_font", "samples/ngs/data/font.png");
    if (jikiAtlas == null) jikiAtlas = new Atlas("ngs_jiki", "samples/ngs/data/jiki.png");
    if (cursorAtlas == null) cursorAtlas = new Atlas("ngs_cursor", "samples/ngs/data/cursor.png");
    if (!gfx.ensure() || !fontAtlas.ensure() || !jikiAtlas.ensure() || !cursorAtlas.ensure()) return false;
    if (font == null) font = new Font(fontAtlas);
    if (input == null) {
      input = (lua.Os.getenv("LUB_NGS_MOCK") != null) ? new MockInput() : new Input();
    }
    if (scene == null) scene = new StubScene();
    return true;
  }

  public static function frame() {
    if (!boot()) return;
    input.refresh();
    scene.update(input.current);
    gfx.beginFrame();
    scene.draw(gfx.drawList);
    gfx.endFrame();
    switch (scene.transition()) {
      case Stay:
      case Switch(s): scene = s;
      case Quit: Lub.quit();
    }
    frameCount = frameCount + 1;
  }
}
```

```haxe
package scenes;

import input.InputSnapshot;
import render.DrawList;
import render.Color;
import game.Game;
import assets.Atlases;

class Title implements Scene {
  static inline var SEL_START: Int = 0;
  static inline var SEL_END: Int = 1;

  var sel: Int = SEL_START;
  var anim: Int = 0;
  var next: SceneTransition = Stay;
  var noGodHeld: Bool = false;

  public function new() {}

  public function update(input: InputSnapshot): Void {
    if (input.dirY < 0) sel = SEL_START;       // up
    else if (input.dirY > 0) sel = SEL_END;    // down
    noGodHeld = input.noGod;
    next = Stay;
    if (input.menu) {
      if (sel == SEL_START) next = Switch(new Play(input.noGod));
      else next = Quit;
    } else if (input.cancel) {
      next = Quit;
    }
  }

  public function draw(dl: DrawList): Void {
    var white: Color = { r: 1, g: 1, b: 1, a: 1 };
    var title = noGodHeld ? "no god shooting game" : "no good shooting game";
    Game.font.drawString(dl, 220, 80, title, white);
    Game.font.drawString(dl, 315, 90, "presented by ngs 2004", white);
    Game.font.drawString(dl, 220, 390, "start", white);
    Game.font.drawString(dl, 220, 420, "end", white);

    var frame = (anim >> 3) & 3;
    var cursorY = (sel == SEL_START) ? 390 : 420;
    dl.sprite(Game.cursorAtlas, Atlases.cursor[frame], 210, cursorY);

    anim = anim + 1;   // draw 後に進める: frame 0 capture で cursor frame 0
  }

  public function transition(): SceneTransition return next;
}
```

- [ ] **Step 1: golden.sh を書く**

`samples/ngs/scripts/golden.sh`。(scene, frame) を回し、両 backend で capture して `tests/golden/ngs/` と比較。本 plan では title のみ (play/gameover は Plan 2/4 で追加)。

```bash
#!/usr/bin/env bash
# NGS golden runner. title screen を frame 0 / 30 で両 backend capture して比較。
#   samples/ngs/scripts/golden.sh            # check
#   samples/ngs/scripts/golden.sh --update   # regenerate
set -euo pipefail
cd "$(dirname "$0")/../../.."   # -> lub repo root

BINARY=./build/lub
ENTRY=samples/ngs/ngs.hxml
GOLDEN_DIR=tests/golden/ngs
BACKENDS=(sokol sdlgpu)
# name:frame の組
CASES=(title_f0:0 title_f30:30)

update=0
[[ "${1:-}" == "--update" ]] && update=1

mkdir -p "$GOLDEN_DIR"
tmp=$(mktemp -d); trap 'rm -rf "$tmp"' EXIT
pass=0; fail=0; missing=0; updated=0

for c in "${CASES[@]}"; do
  name="${c%%:*}"; frame="${c##*:}"
  for bk in "${BACKENDS[@]}"; do
    out="$tmp/ngs_${name}_${bk}.png"
    golden="$GOLDEN_DIR/ngs_${name}_${bk}.png"
    LUB_BACKEND="$bk" scripts/run-headless.sh "$BINARY" "$ENTRY" \
      --capture "$out" --capture-frame "$frame" >"$tmp/${name}_${bk}.log" 2>&1
    if [[ ! -f "$out" ]]; then
      echo "FAIL ${name} ${bk}: no capture (see $tmp/${name}_${bk}.log)"; fail=$((fail+1)); continue
    fi
    if [[ $update -eq 1 ]]; then cp "$out" "$golden"; echo "UPDATED $golden"; updated=$((updated+1)); continue; fi
    if [[ ! -f "$golden" ]]; then echo "MISSING $golden"; missing=$((missing+1)); continue; fi
    if cmp -s "$out" "$golden"; then echo "PASS ${name} ${bk}"; pass=$((pass+1));
    else echo "FAIL ${name} ${bk}: $out != $golden"; fail=$((fail+1)); fi
  done
done
echo "---"
[[ $update -eq 1 ]] && { echo "updated: $updated"; exit 0; }
echo "pass: $pass  fail: $fail  missing: $missing"
[[ $fail -eq 0 && $missing -eq 0 ]]
```
