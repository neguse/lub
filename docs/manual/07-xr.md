# XR (OpenXR / WebXR)

`Xr` は VR ヘッドセットの視点と入力を、他の API と同じ即時モードで返す。
native は OpenXR (Linux の Vulkan backend、`--backend openxr`)、web は WebXR
(`web/xr.mjs` の `createXR`) に接続し、ゲーム側の書き方は同じ。

## 面

| API | 内容 |
| --- | --- |
| `Xr.Active()` | XR セッションが動いているか。 |
| `Xr.Focused()` | 入力フォーカスを持つか。システムメニューが前に出ると false。 |
| `Xr.View(eye, near, far)` | 片眼の `XrView`。左 0、右 1。この frame に描けないなら null。 |
| `Xr.Input(hand)` | 片手の `XrInput`。左 0、右 1。セッションが無ければ null。 |

`XrView` は描画先 `Target`、解像度 `Width` / `Height`、LOCAL 空間の眼の
`Position` (メートル) と `Orientation` (xyzw)、`ViewProjection` (行優先の
projection * view、前方 -Z、深度 [0,1]) を持つ。LOCAL 空間は起動時の頭の位置が
原点で、ゲーム側で基準を取り直すには lubx の `XrAnchor` を使う。

`XrInput` は `Active`、スティック `StickX` / `StickY`、`Trigger` / `Grip` (0..1)、
ボタン `Primary` / `Secondary` / `Menu` / `StickClick`。Steam Frame と
Oculus Touch のコントローラーを同じ面に写す。

## 片眼へ描く

眼の描画先は `XrView.Target` の `TextureRef` で、`PassOpts.Target` に渡す。
`MainTex` と同じ扱いで、depth は既定のものを使い、他の target と組み合わせない。
`Active()` の間は `MainTex` への pass は error になる。

```csharp
public static void OnFrame(float dt)
{
    if (!Xr.Active())
    {
        Gfx.BeginPass(new PassOpts { Target = Gfx.MainTex });
        DrawScene(Camera3d.Vp(camera));
        Gfx.EndPass();
        return;
    }
    for (var eye = 0; eye < 2; eye++)
    {
        var view = Xr.View(eye, 0.05f, 500);
        if (view == null)
        {
            return;
        }
        Gfx.BeginPass(new PassOpts { Target = view.Target });
        anchor.ViewProjection(view, viewProjection);
        DrawScene(viewProjection);
        Gfx.EndPass();
    }
}
```

両眼とも描いた frame だけがヘッドセットに送られる。片眼だけ描いた frame や、
`View` が null の frame は送られない。MRT や後処理が要るゲームは自分の
render target に描き、最後の pass で `Target = view.Target` に合成する。

## 基準姿勢 (lubx.XrAnchor)

```csharp
static readonly XrAnchor anchor = new XrAnchor();
static readonly float[] viewProjection = new float[16];

// ゲーム開始時やユーザー操作で基準を取る
var left = Xr.View(0, 0.05f, 500);
var right = Xr.View(1, 0.05f, 500);
if (left != null && right != null) anchor.Recenter(left, right);
```

`Recenter` は両眼の中点と水平方向の向きを基準に取り、`ViewProjection(view, result)` が
その基準を原点・前方 -Z とする空間の行列 (行優先の float[16]) を書く。傾き (pitch / roll) は基準に
含めないので、床は水平のまま。

## 入力の読み方

スティックとトリガーは毎フレームの生の値なので、しきい値の判定と
ヒステリシスはゲームで持つ。`Active` が false の手は接続されていないか
スリープ中。フォーカスを失うと両手の `Active` が false になる。

## native と web

native は `LUB_BACKEND=openxr` で起動する。OpenXR runtime (Steam Frame では
SteamVR) と `XR_KHR_vulkan_enable2` が必要で、SDL の window は使わない
(`SDL_VIDEO_DRIVER=dummy`)。frame の間隔は OpenXR の予測表示時刻から取り、
`OnFrame` の dt に渡す。

web は `web/xr.mjs` の `createXR` がボタンを出し、immersive-vr セッションの
開始と終了を扱う。セッション中は両眼の描画先を canvas に左右に並べ、WebGL の
XR レイヤーへ転送する。詳細は `web/README.md`。
