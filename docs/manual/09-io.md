# ファイルとアセット

`Io` はホットリロード前提のファイル入出力 API。更新時刻と内容ハッシュでキャッシュされるため、毎フレーム呼び出しても負担が小さい。

## 読み込み (`Io.Load*`)

```csharp
Io.LoadText("data/config.txt", out var text, out var version, out var status, out var error);
if (text == null) return;
```

`Io.LoadText`・`Io.LoadBytes`・`Io.LoadGltf` はすべて同じ `out` 引数パターンを取る:

| 引数 | 意味 |
| --- | --- |
| `text` / `data` / `mesh` | 読み込んだ内容。準備できるまで `null` |
| `version` | 内容の FNV-1a ハッシュ。`Gfx.Use*` などの `version` にそのまま渡せる |
| `status` | `Io.Status.Ready` / `Pending` / `Error` |
| `error` | `Error` のときの理由文字列 |

- `null` の間はそのフレームをスキップする書き方にしておくと、非同期取得を伴う環境でもそのまま動く。
- 通常のファイルはネイティブ・Web とも起動時に用意されたものから同期で読まれ、存在しないパスはその場で `Error` (`"missing"`) になる。Web で読ませたいファイルは起動前に MEMFS へ配置する (`lub export web` では自動で行われる)。

## パスの規約

パスは起動時のカレントディレクトリ基準の相対パスで書く。
ゲームディレクトリから `lub Game.csproj` で起動する場合は `data/config.txt` のように書く。

## セーブデータ (`save/`)

`save/<名前>/<ファイル>` で始まるパスは、ユーザーごとの保存領域を指す。
`<名前>` には他のゲームと重ならないゲーム固有の名前を付ける。

| プラットフォーム | 保存先 |
| --- | --- |
| Linux | `$XDG_DATA_HOME/<名前>/` (既定は `~/.local/share/<名前>/`) |
| Windows | `%APPDATA%\<名前>\` |
| macOS | `~/Library/Application Support/<名前>/` |
| Web | IndexedDB (ページの origin ごと) |

```csharp
Io.LoadText("save/mygame/scores.txt", out var text, out _, out var status, out _);
if (status == Io.Status.Pending) return;
// 読み込み完了後に更新して保存する
Io.SaveText("save/mygame/scores.txt", newScores);
```

- Web では起動直後に IndexedDB から読み込み終わるまで `LoadText` が `Io.Status.Pending` を返し、その間の `SaveText` はエラーになる。保存する前に `Pending` が終わるのを待つ。
- IndexedDB が無効な環境では読み込み・保存ともエラーになる。またブラウザが長期間未訪問のサイトの保存データを消す場合がある。
- `<名前>` やファイル名が空のパス、`.` や `..` を含むパスはエラーになる。

## ファイル形式ごとの扱い

- `Io.LoadText`: テキスト全般 (Slang シェーダ、設定ファイルなど)
- `Io.LoadBytes`: バイナリ全般 (画像、フォント、音声など)
- `Io.LoadGltf`: glTF (`.gltf` / `.glb`)。結果は `Io.InterleavePn` 等のヘルパで頂点列にして `Gfx.UseBuffer` へ渡す
- 画像の展開は `Png`、フォントは `Font` / `Lubx.Text`、音声は `Audio` / `Lubx.Sfx` を使う

## `Lubx.Assets` の定型ヘルパ

読み込みとリソース宣言を 1 行にまとめたヘルパ。毎フレーム呼び続け、未準備の間は `null` を返す:

- `Assets.Shader(key, vsPath, fsPath)`: 頂点・フラグメントの Slang を読んで `Gfx.UseShader`
- `Assets.Wav(key, path)`: `Io.LoadBytes` + `Audio.Decode` + `Audio.SndBytes` (同一 `version` の音源があれば再デコードしない)
- `Assets.Ogg(key, path)`: `Io.LoadBytes` + `Lubx.Vorbis.Decode` + `Audio.SndBytes` (同上)
- `Assets.RenderTarget(key, w, h, fmt)`: オフスクリーン描画用の `Gfx.UseTexture` (既定は Linear / Clamp。サイズ変更で作り直す)
