## Client-side C# compiler (web playground)

The web playground compiles C# to Lua in the browser with the TinyC# compiler
(`third_party/tcs`, MIT) published as a .NET WebAssembly bundle. The bundle is
generated by `web/scripts/gen-tcs-assets.mjs` into `web/tcs-wasm-assets/`
(gitignored) and deployed with the site.

| Component | Path (generated) | License | Source |
|-----------|------------------|---------|--------|
| TinyC# (tcs) compiler + TinySystem | web/tcs-wasm-assets/_framework/WasmCompiler.wasm, TinySystem.wasm | MIT | https://github.com/neguse/tcs |
| .NET runtime for WebAssembly (dotnet.js, dotnet.native.wasm, System.*.wasm) | web/tcs-wasm-assets/_framework/ | MIT | https://github.com/dotnet/runtime |
| Roslyn (Microsoft.CodeAnalysis*.wasm) | web/tcs-wasm-assets/_framework/ | MIT | https://github.com/dotnet/roslyn |

各依存先のフルテキストは `third_party/<component>/LICENSE` または上記 Source URL を参照。
