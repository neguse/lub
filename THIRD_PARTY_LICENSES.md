## Client-side C# formatter (web site)

The web site formats the C# that the editor saves, in the browser, with a
.NET WebAssembly bundle of CSharpier (`tcs/WasmCompiler`). The bundle is
generated by `web/scripts/gen-tcs-assets.mjs` into `web/tcs-wasm-assets/`
(gitignored) and deployed with the site.

| Component | Path (generated) | License | Source |
|-----------|------------------|---------|--------|
| Formatting entry (WasmCompiler) | web/tcs-wasm-assets/_framework/WasmCompiler.wasm | MIT | `tcs/WasmCompiler/` (this repository) |
| .NET runtime for WebAssembly (dotnet.js, dotnet.native.wasm, System.*.wasm) | web/tcs-wasm-assets/_framework/ | MIT | https://github.com/dotnet/runtime |
| Roslyn (Microsoft.CodeAnalysis*.wasm) | web/tcs-wasm-assets/_framework/ | MIT | https://github.com/dotnet/roslyn |
| CSharpier (CSharpier.Core.wasm) | web/tcs-wasm-assets/_framework/ | MIT | https://github.com/belav/csharpier |

各依存先のフルテキストは `third_party/<component>/LICENSE` または上記 Source URL を参照。

Steam Frame の ARM64 配布物では `python3 tools/package-frame-licenses.py <native-directory>`
で同梱用の `THIRD_PARTY_NOTICES.txt` を生成する。Slang の内蔵依存の通知は
`third_party/slang/THIRD_PARTY_NOTICES.txt` にあり、対象バイナリは生成時に照合する。
